# What a session needs that the code does not say

`AGENTS.md` says what this system is and how to run it. `CLAUDE.md` is the evidence: 1,500 lines
of what was measured, in order. Neither says **how to work here**, and that is what kept getting
re-learned at the cost of an afternoon each time.

This folder is that. It was carried out of one agent's private notes and into the repository on
2026-09-27, because notes a session cannot read are notes that do not exist. Rules here are
process, not engineering — each one is written with what it cost to find out, so you can judge
whether your situation is the same.

Read in this order:

1. **`AGENTS.md`** — the system, the lane, the four rules that are not negotiable, and the
   section *With this folder alone*, which says exactly what a clone can do.
2. **`working-rules.md`** (here) — how to run a round without repeating a known mistake.
3. **`CLAUDE.md`** — only when you need the measurement behind a particular claim. It is a log,
   not an introduction, and it is long on purpose.

What is NOT here, deliberately: anything already stated in `AGENTS.md` or `CLAUDE.md`. Two copies
of a rule drift, and this repository has been bitten by exactly that — a brief on disk that was a
day behind the schema beside it, and an author who followed the stale one and filed the
photograph's most visible feature as a missing capability. Where a rule already has a home, this
folder points at it instead of restating it.

The rest of `memory/elevation-3d/` is older: the approach studies, the input/output contracts and
the assets from the 2026-08 work. They are history, kept because their measurements are still
quoted.
