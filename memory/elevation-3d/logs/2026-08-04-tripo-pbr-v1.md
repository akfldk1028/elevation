## Root-cause investigation

- Official Tripo documentation supports `import_model` task IDs, `texture_prompt.style_image`, `v3.0-20250812`, standard PBR, geometry alignment, baking, and texture seed.
- The official Python SDK uploads multipart files through `/upload` and serializes any texture prompt image as `{ type: "jpg", file_token: ... }`, including local PNG inputs.
- Matching `/upload` alone did not resolve `1004`, so endpoint selection was not the sole cause.
- The adapter matches the SDK upload endpoint and descriptor, and now uses `texture_prompt.image` for the approved architectural appearance target. This semantic correction is covered by a failing-then-passing regression test and was verified by the single successful paid task.
