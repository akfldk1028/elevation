# Problem Definition

## Correct task

The task is not to generate four unrelated elevation images. It is to create one appearance-bearing 3D representation from a locked MASS and then obtain every render and drawing from that shared 3D result.

## Inputs

- authoritative mesh and geometry program;
- locked front, right, back, left, top, and axon PNGs;
- view/projection matrices and projected bounds;
- facade planes and surface normals;
- pre-legal floor guides;
- candidate identity and manifest hashes;
- a facade design brief or reference image.

## Outputs

- a textured 3D representation tied to the source identity;
- reproducible axonometric and orthographic renders;
- drawing images using the same camera definitions;
- evidence recording provider calls and geometry verification.

## Non-goals

- regenerating or improving the MASS geometry;
- changing the storey count or silhouette;
- legal, planning, parking, FAR, or BCR approval;
- using a contact sheet as geometry authority;
- launching a paid multi-candidate batch by default.
