# Failure Catalog

## Provider failures

- unsupported regional account or authentication;
- request image package exceeds provider limits;
- timeout or expired result URL;
- content moderation rejection;
- undocumented model-version behavior change.

## Geometry failures

- vertex displacement;
- topology replacement or remeshing;
- cropped wing, court, bridge, notch, or radial edge;
- lost roof or underside surfaces;
- changed ground contact.

## Appearance failures

- extra or missing storey bands;
- windows crossing floor guides;
- corner materials that do not continue;
- front/back duplication or Janus effect;
- baked lighting interpreted as material;
- generic stacked facade substitution;
- incomplete projection coverage.

## Drawing failures

- incorrect matrix convention;
- mirrored or swapped views;
- perspective output where orthographic output is required;
- hidden edges presented as visible outlines;
- non-repeatable crop or scale.
